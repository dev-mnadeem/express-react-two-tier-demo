# Fitco users client

React 18 single-page client, built with Vite, for the user-management API in [`../api`](../api).

See the [project README](../README.md) for the architecture, the sequence
diagram and the full quickstart. In short:

```bash
npm install
cp .env.sample .env     # point VITE_API_URL at the API
npm run dev             # http://localhost:8701
npm test                # Vitest + React Testing Library, network fully mocked
npm run lint
```
